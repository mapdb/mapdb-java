mapdb-collections

About

mapdb-collections is a collections framework for Java, distributed under the org.mapdb.collections namespace. It is a fork of Eclipse Collections, retaining its JDK-compatible List, Set and Map implementations, the additional types not found in the JDK like Bags and Multimaps, and the set of utility classes that work with any JDK-compatible Collections, Arrays, Maps or Strings.
